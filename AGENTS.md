# Project Agent Instructions

## Review cadence

**One code review at the end of a complete feature — not per task.**

When using `superpowers:subagent-driven-development`, skip the per-task spec-compliance and code-quality review loops. Run a single final review using `superpowers:requesting-code-review` after all tasks are complete.

Why: per-task reviews burn tokens and slow delivery without meaningfully improving quality on a focused implementation plan.
